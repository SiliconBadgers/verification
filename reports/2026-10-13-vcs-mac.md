## Reproduce

Keep RTL, Software and Architecture as siblings, or override the Make variables.
The vector-generator and contract contents used for this run are identified below.

```sh
module load synopsys/vcs-mx/2026.03
make doctor
make test
make style
```

`run.py` records input fingerprints, compiler/runtime exits, elapsed time and
actual check counts in `build/mac/vcs/summary.json`. Compile and runtime output
are retained in `compile.log` and `run.log`. The shared VCS helper rejects an
unsupported tool version, enables assertions and uses `-exitstatus`.

## Failure detection and limits

A separate vector file with a deliberately incorrect expected result produced
a golden-vector mismatch and simulator/runner exit 3. The unmodified reference
vectors passed. Compilation of the negative case succeeded, so its nonzero exit
was an exercised checking failure, not a missing-tool or build error.

The RTL helper's unit tests cover failure exits, missing executables, timeout,
unsupported compiler versions, and rejection of alternate simulators. Source
style passed for this repository, including the root `run.py`.

Code, functional and assertion coverage were **not measured**. No coverage
database or URG report was collected. This test does not establish full-SoC
correctness, timing, synthesis, CDC/reset safety, or coverage closure.
